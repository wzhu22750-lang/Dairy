## 1. 产品变化（Before / After）

| 维度 | Before（v1.x · iOS 极简毛玻璃） | After（v2.0 · 私人数字书） |
|---|---|---|
| 产品隐喻 | 一个功能完整的日记工具 App | 一本随时间生长的私人书 |
| 首页 | 卡片流 + 分段筛选器 + 心情胶囊 + 玻璃 TabBar | 书页：年/月章节 + 衬线日期页码，内容直接印在纸上 |
| 打开一篇日记 | 直接进入编辑器（Markdown 源码 + 光标 + 工具栏） | 进入阅读页（Kindle 式排版），编辑是阅读页里的一个动作 |
| 保存模型 | 手动点"完成"，忘记即丢失 | 落笔即保存（800ms 防抖草稿 + 生命周期关口 flush + 草稿恢复） |
| 色彩 | 黑白灰 + 系统蓝 + 毛玻璃半透明 | 全应用零饱和 E-ink 色板，唯一彩色是朱砂（破坏性操作） |
| 排版 | 系统无衬线，字号行距锁定 | 衬线书页正文，字体/字号/行距/页宽全局可调、持久化 |

## 2. UI 变化（全部页面）

- **书页（原首页 Timeline）**：年份淡墨一行、月份章节标签、大号衬线日期作页码；每天的内容为"标题 + 预览正文 + 插图行"，无卡片、无边框、无心情/天气胶囊；置顶只留一枚小图钉注脚；天与天之间以 0.5dp 发丝线分页。长按呼出置顶/编辑/回收站操作单。
- **编辑器（数字纸张）**：进入即见"日期页眉 + 标题 + 正文"三件事；心情/天气选择器与 Markdown 工具栏全部移除；底部只剩"插图 / 附加信息"两个动作与字数；顶栏是返回、日期、保存状态（保存中… / 已保存 HH:mm）。外部协作增强：草稿持久化引擎（Room drafts 表 + 恢复提示）。
- **阅读页（新增）**：内容占满纸面，顶栏与底栏随滚动隐现，点击纸面进入沉浸模式；顶缘一根发丝线是阅读进度；底栏显示"约 N 分钟"；Aa 调出排版面板；正文按 Markdown 块渲染（标题/引用/列表/待办/分割线/插图），行内支持粗体/斜体/代码；未内联的旧附件作为末尾插图呈现；插图可全屏查看（轻触关闭）。
- **目录（原日历）**：月份如章节翻动，衬线数字网格，有字的日期留一枚淡墨点；选中日期以淡墨晕染圈出，下方直接印出该日书页，空日提供"补写这一页"。
- **检索**：下划线式检索行 + 标签筛选，结果按日期分组印在纸上；移除心情/天气筛选行。
- **回声（原那年今日）**："N 年前的今天"成为注脚，回声正文用与书页一致的排版。
- **刻度（原统计）**：三个大号衬线数字（连续天数/页数/字数）+ 常写标签清单；入口从首页迁至设置页，刻意降低存在感。
- **废纸篓**：书籍隐喻（"撕下的书页停留三十天"）；修复审计发现的两处问题——单条永久删除补上确认对话框、删除时间改为剩余语境表达。
- **锁屏**：修复 6 圆点与 4 位 PIN 不一致；键盘数字改衬线体。
- **设置**：四个区块保留；"纸面与排版"接通真实设置（原主题/字体是只改本地状态的假开关）；新增"阅读排版"直通 Aa 面板；图标位去除彩色方块。
- **导航**：4 栏索引条压平（书页/目录/回声/设置），墨色激活态；模态转场统一为 200ms 淡入 + 4% 轻微上滑，Tab 间 180ms 交叉淡入。

## 3. 新设计系统（Dairy Design System 2.0）

- **色彩（`InkPalette`/`InkTones`）**：浅色 = 纸张白 `#FBFAF7` + 墨字 `#1D1C1A` 三级墨阶 + 发丝线 `#E7E4DD`；深色 = 柔和黑 `#151412` + 暖白 `#E6E3DB` 三级墨阶 + 夜间发丝线；顶/底栏 97% 纸色；`Cinnabar #B3432B` 为全应用唯一彩色（仅破坏性操作）。契约测试强制核心色板饱和度 ≤ 0.20。
- **排版（双层）**：界面骨架 = 无衬线小字（Material3 阶梯收敛，最大 24sp）；书页正文 = `InkType` 动态样式（默认衬线 18sp × 1.75 行距，随设置缩放）。`ReadingSettings`（字体/字号 0.8–1.4/行距 1.4–2.2/页宽 0.75–1/主题模式）经 DataStore 持久化、`LocalReadingSettings` 注入全树。
- **布局**：书页边距 24dp；插图全幅 2dp 微圆角、4:3；天际距 22dp；段落距 14dp。
- **形状**：印刷品式微圆角（2–18dp），胶囊仅用于极小标签。
- **材质**：毛玻璃压平为实心纸面 + 0.5dp 实色发丝线（API 兼容层保留）。
- **动效**：按压 scale 0.98 + 透明度衰减 + 触感反馈（无水波纹）；进度条与列表滚动 180–220ms FastOutSlowIn；无装饰性动画。

## 4. 删除功能

- **心情系统整体移除**：`Mood` 枚举、编辑器心情选择行、时间线心情筛选胶囊、检索心情筛选、日历心情徽章、`MoodIcon` 全套手绘图标、统计心情分布、TXT 导入心情识别、备份导出心情字段。数据库实体列保留（`fallbackToDestructiveMigration` 下删列会清空用户数据），写入固定值 `"CALM"` 兼容历史数据。
- **天气降级为附加信息**：不再提供任何主动填写入口；历史天气在阅读页元信息行以文字呈现；`WeatherIcon` 移除。
- **编辑器 Markdown 工具栏**（H1/H2/B/I/列表/待办/引用/分割线快捷键）：写作回归纯文本纸面，Markdown 语法在阅读页照常渲染。
- **时间线分段筛选器与 TXT 导入死入口**：检索承担查找职责。
- **统计页首页入口**：迁移至设置页"书的刻度"。
- **废弃代码**：`PaperColors` 兼容别名层、`StampBadge`、`NavRoutes` 死注释（保留为路由契约）、无引用导入。

## 5. 新增能力

- **阅读页 + 沉浸模式**（点击纸面隐藏全部 chrome，滚动方向感知隐现）。
- **Aa 阅读设置面板**：字体（衬线/无衬线）、字号步进、行距三档、页宽三档、纸面（日/夜/随系统）——全局即时生效并持久化。
- **自动保存体系**（与外部协作的草稿引擎整合）：防抖落盘、`onStop` flush、进程死亡后草稿恢复、空白草稿自动清理。
- **轻量 Markdown 书页渲染器**（`MdParser`）：块级 + 行内样式，图片按书页插图呈现，支持全屏查看器。
- **书页结构**（年/月/日章节、置顶注脚、页脚字数落款）与"约 N 分钟"阅读时长。
- 修复审计发现的隐患：锁屏位数不一致、废纸篓单条永久删除无确认、设置页假开关（主题/字体/自动锁定延迟中原两项为纯本地状态）。

## 6. 用户体验提升

- **第一次打开**：空书页只有一句"还在第一页。写下今天的第一个字，这本书就开始了。"与"开始书写"——零筛选噪音，唯一 CTA。
- **每天打开**：今天的一页就在章节最上方，正文可直接读；写 = 点笔尖图标，落笔即存，无"完成"心智负担。
- **重读旧日记**：默认阅读排版而非编辑器；沉浸模式只剩文字；进度与时长给出"读书"的体感。
- **查找**：一条检索线直达全文/标题/地点，标签一步进入。
- **长期陪伴**：时间书随年份自动长出章节；排版偏好一次调好终身跟随；夜间纸面呵护睡前阅读。

## 7. 后续路线

1. **翻页动效**：阅读页横滑翻页（仿真/平移两档），需处理长文分页算法。
2. **字体包**：内嵌开源衬线字库（思源宋体子集）替代系统 serif，保证各机型一致的 Book 气质。
3. **正文内插图编辑**：插入图片时写入 `![](path)` 至光标处，编辑器内联预览，实现真正的图文混排写作。
4. **草稿系统收尾**：草稿与阅读页/时间线的状态联动打磨（外部协作项，接口已就位）。
5. **导出为书**：按年份生成 EPUB/PDF"年度成书"。
6. **无障碍与本地化**：TalkBack 语义补全（当前部分自绘符号缺 contentDescription）、英文界面。
